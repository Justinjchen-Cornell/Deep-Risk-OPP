What this is

A 10-item checklist for the 2026 Q4 macro regime: valuation, leverage, policy, and capital flows. Each item is scored ● / ◐ / ○ / ?. We don't sum the score; we look for clusters.

This is not a prediction. It is a pre-registered way to be wrong in public — and to learn from it.

How to use it

  • Score first, read later. Write your own score before reading the evidence.
  • Look for clusters, not totals. One signal is noise; three in the same cluster is a regime.
  • Re-score in December. Mark: data error / judgment error / regime actually changed.
  • Do not change the machine. This checklist sits beside the card; it does not override it.
