## 七、文案模板

### 1. 全平台统一简介（中文）
> 独立宏观研究者。金油比框架作者：把预言写成合同，数据开源，认错公开。每日信号免费订阅，AI 13人评审每月更新。

### 2. 知乎长文开头模板（钩子式）
> 开头：一个反常识结论 + 为什么它和你有关
> 例："过去六年，全球债券投资者的收益只有一个变量：汇率。利息、价格都不重要了——你以为是选债券，其实是选货币。"
> 中段：数据链条（每 2-3 段一个数字或图）
> 结尾：三件套 = 结论一句 + 免费资源（GitHub/订阅）+ 互动提问

### 3. 星球开张帖（免费期第一篇）
> 标题：一个把预言写成合同的宏观实验室
> 内容：我是谁（一段）→ 我提供什么（报告/信号/评审/认错四件套）→ 免费期送什么（完整报告 PDF）→ 未来付费什么（解读+评审+日历）→ 免责

### 4. 雪球动态模板
> 【金油比·每日】GOR xx.x（区间）· 仓位 xx% · 今日信号一句话 + 图
> 【认错】上月我说了 X，实际 Y。错在 Z。下次改成 W。
> 【框架】五环逻辑链第 N 环：一句话观点 + 证据 + 免费全文链接
