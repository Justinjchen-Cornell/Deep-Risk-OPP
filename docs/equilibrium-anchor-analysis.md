# GOR 均衡锚漂移分析（2026-08-13 · 实证）

> 用 20 年数据（2006-08 → 2026-08，5,179 交易日，新浪 XAU/CL）回答一个必须回答的问题：
> **"历史均衡 15-25"的锚，被央行购金、页岩油、能源转型抬走了吗？**

## 一、全样本分布

| 分位 | GOR |
|---|---|
| P10 | 10.9 |
| P25 | 15.2 |
| **P50** | **21.0** |
| P75 | 27.4 |
| P90 | 44.4 |
| 均值 | 24.1 |

全样本中位数 21.0 恰好落在"15-25"区间内——**旧锚在全样本口径下依然成立**。

## 二、但锚在持续上移（核心发现）

5 年滚动均值：

```
2011: 12.9  →  2016: 16.6  →  2021: 29.1  →  2026: 35.4
```

分段对比：

| 时段 | 均值 | 中位 | GOR>45 天数占比 | GOR>60 占比 |
|---|---:|---:|---:|---:|
| 2006-2012 | 13.7 | 14.2 | **0.0%** | 0.0% |
| 2012-2018 | 21.0 | 21.0 | 0.1% | 0.0% |
| 2018-2026 | **34.2** | 27.7 | **23.7%** | 7.6% |

**结论：均衡中枢从 2006-2012 年的 ~14，上移到 2018-2026 年的 ~28-34。** "GOR>45 极端"在 2006-2012 六年里一次都没出现过；2018-2026 却有近 1/4 的时间高于 45。当前 53.8 相对旧锚是"1986 年以来最极端"，相对 2018 后的新锚只是 P92 附近。

## 三、漂移的结构性驱动

| 力量 | 方向 | 机制 |
|---|---|---|
| 央行购金（PBoC 19月增持、45%央行计划增持） | 抬金 | 黄金需求曲线结构性上移，金价中枢抬升 |
| 页岩油供给弹性 + 电动车渗透 | 压油 | 原油长期需求曲线右移放缓，油价中枢下移 |
| 能源转型资本开支转移 | 压油 | 传统油气 capex 长期不足 → 短期托油价、长期压需求 |
| 美联储债务货币化路径 | 抬金 | 美元实际购买力稀释，硬资产溢价 |

前两项是慢变量、结构性的——**锚的上移更可能是永久性的，而非周期性的**。

## 四、对框架的含义（三条纪律）

1. **表述修正**：不得再说"历史均衡 15-25"而没有时间限定。正确表述：
   > "全样本（2006-2026）中位 21；但中枢已从 2006-2012 的 ~14 上移至 2018-2026 的 ~28-34。当前区间阈值 45 仍对应全样本 P90 水平。"
2. **阈值 45 暂时保留**：45 ≈ 全样本 P90（44.4），"极端"定义仍有统计基础。但必须**每季度复核**分位数——若全样本 P90 继续上移并超过 45，应触发阈值重校准流程（改用滚动分位数定义极端区）。
3. **证伪条款必须与锚挂钩**（见 track-record.md）：若 2028 年中 GOR 5 年均值 >40 且油价未出现 +54% 反弹，则"均值回归"假设本身失效——框架需要从"单比率回归"升级为"锚随结构漂移"的版本。

## 五、数据与方法

- 数据：`看板日志/backtest_cache/gold_wti_history.csv`（新浪 XAU 现货 + CL，2006-08 → 2026-08，5,179 天）
- 方法：5 年滚动均值 + 三段分位对比；GOR = Gold ÷ WTI 日频
- 复现：`python -c` 读缓存 CSV 即可，无需联网
- 局限：XAU 现货对 COMEX 期货存在基差；CL 含合约换月跳空（未做展期调整）——换月跳空会**低估**真实滚动收益、对 GOR 分布影响有限（同日比值）
