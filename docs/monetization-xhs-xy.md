## 0. 合规红线（越过=封号+法律风险，不是开玩笑）

1. **荐股/证券投资咨询需要牌照**。无牌提供"买什么、何时买"的建议，违反《证券法》及《证券、期货投资咨询管理暂行办法》，情节严重的涉非法经营罪。只写"不构成投资建议"**不能豁免实质荐股行为**——产品形态本身必须是"研究材料/数据工具"，而不是"操作指令"。
2. **小红书财经内容需资质认证**。无资质发投资类内容会被限流；"荐股""喊单"类直接封号。
3. **闲鱼对"投资建议"类虚拟商品会下架**，且虚拟商品退款纠纷中卖家举证困难。

**可卖的（合规）**：方法论手册、数据可视化、回测报告、工具部署服务、付费订阅研究。
**不能卖的**：个股/期货买卖点、"跟单""带盘"、收益承诺。

## 2. 小红书打法（获客阵地）

### 人设定位
**不是"财经博主"（要资质、被限流），是"把预言写成合同的数据研究者"**。内容=工具/可视化/实证，从不出现"建议买入"。

### 账号搭建（手把手）
1. 注册小红书 → 昵称 "Justinjchen·金油比研究"
2. 简介："把宏观预言写成带截止日期的合同 · 每日自动更新的数据系统" + 主页链接位放站点
3. 先养号 1 周：每天发 1 篇"数据可视化"笔记，不带任何投资导向
4. 申请财经资质认证（小红书创作者中心 → 资质认证 → 上传相关材料；个人无牌照就选"知识分享"类）

### 内容模板（笔记 3 件套）
```
封面（大字报风格）: 
  "我把预言写成了合同"
  "2027.6.19 前 WTI 必须到 $107.60"
配图 3 张:
  ① dashboard 截图（GOR 54.4 大字）
  ② 20年回测曲线（Sharpe 1.42 vs 0.37）
  ③ 证伪条款文档截图
文案（300字内）:
  钩子 + 3个数字 + 链接 + "研究框架，不构成投资建议"
话题: #金油比 #原油 #宏观研究 #数据可视化
```
频率：每周 3 篇（钩子轮流：合同/诚实回测/锚漂移）。

### 变现路径
- **小红书店铺**上架《手册 PDF》（平台内交易，最合规）
- 专栏/合集付费（100 元/月，平台抽成 10-30%）
- 流量起来后：简介引导至知识星球（小红书对导流微信零容忍，但"主页链接"可放星球链接）

### 预期（说实话）
财经内容在小红书限流严重，0-1 阶段 3 个月涨粉 1000 是正常速度。别指望爆款，指望**精准长尾**：搜"金油比"的人就是目标用户。

## 3. 闲鱼打法（长尾变现测试场）

### 定位
闲鱼不是品牌阵地，是**付费意愿测试器**：有人愿意花 9.9 买你的 PDF，说明需求真实存在。

### 上架步骤（手把手）
1. 打开闲鱼 → 底部"+"→ 发布 → 类目选"虚拟商品/电子文档"
2. 商品 1：《GOR金油比框架完全手册·2026版》定价 29.9，主图用手册封面
3. 商品 2：《宏观数据管道部署教程》定价 99，主图用仪表盘截图
4. 商品 3：《金油比20年回测数据集+代码》定价 49，主图用回测曲线
5. 标题埋词："金油比 原油 黄金 宏观分析 研究框架"（闲鱼搜索=免费流量）
6. 描述必写："虚拟商品，发货后不退"；**全篇不出现"投资建议""推荐买卖"字样**
7. 每天擦亮（闲鱼流量机制），回复询问时引导"具体数据需求可定制"

### 红线
- 标题/描述禁用"荐股""跟单""带赚"
- 不卖"买卖点信号"；只卖"研究材料"
- 差评风险：虚拟商品纠纷平台倾向买家——发货用网盘链接+截图留证

### 预期
闲鱼单品月销 10-50 单是正常天花板（几百到几千元/月）。它的真正价值是**验证**：哪个产品有人买，就把哪个产品搬去小红书/星球主推。
