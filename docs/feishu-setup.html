DEEP-RISK-OPP · FEISHU ALERTS

用飞书接收告警，1 分钟。

不需要服务器，不需要飞书应用审核。一个群机器人 + 一个 GitHub Secret。

1在飞书群里创建自定义机器人
飞书群 → 设置 → 群机器人 → 添加机器人 → 自定义机器人 → 复制 Webhook 地址。
2把 Webhook 存成 GitHub Secret
打开下面的页面，名称填 FEISHU_WEBHOOK，值粘贴上一步的地址。
打开 GitHub Secret 页面 查看已有 Secrets
3发一条测试消息
打开 Actions → Feishu Test → Run workflow。收到消息即接通。
打开 Feishu Test
⚡或者：一条命令搞定（本机）
在项目目录运行向导：它会发测试消息，并通过 gh 自动写入 Secret。
python scripts/feishu_setup.py

安全说明：Webhook 本身就是密钥，不会被编进任何二维码或提交进仓库。二维码只打开本页或 GitHub Secret 页面。若 webhook 泄露，在飞书群机器人设置里重置即可。

接入后：P0/P1 告警 → 飞书（主通道）+ GitHub Issue（零配置兜底）。设计见 docs/v3.0-alerting-design.md。
