## 各平台打法

### 1. 微信公众号 — 主战场

| 环节 | 操作 |
|------|------|
| **定位** | "量化地缘风险 × 六大师投资框架" |
| **发布节奏** | 每周1篇免费长文 + 每月1篇付费深度 |
| **免费内容** | 执行摘要 + 一张决策树图 + 三情景概览 |
| **付费内容** | 完整分阶段日历 + 三档组合模板 + 监控指标清单 |
| **付费定价** | 单篇 ¥9.9（测试）→ 稳定后 ¥19.9/篇 |
| **涨粉策略** | 雪球/知乎文末引导关注 + 决策树图自带传播力 |

**标题公式**：
> 《33天。美伊停战只给你这么多时间。数学是这么说的。》
> 《六位投资大师对中东停战的共识：85%看多能源》
> 《一张决策树，看懂中东停战后的全部路径》

### 2. 雪球 — 引流引擎

| 环节 | 操作 |
|------|------|
| **定位** | 量化宏观 + 地缘风险分析 |
| **发布内容** | 精简版长文（去掉付费部分）+ 决策树图 |
| **互动策略** | 主动参与油价/黄金/美股讨论，建立专业人设 |
| **引流方式** | 文末："关注公众号【XXX】，获取完整六大师深度分析和分阶段执行日历" |
| **频率** | 每周1-2篇 |

**雪球特别提醒**：
- 不要直接推荐A股代码（合规红线）
- 用"能源龙头""黄金ETF""商品基金"等模糊表述
- 强调"研究框架"而非"投资建议"
- 历史回测比预测更安全——多引用2020年GOR极端后的油价反弹案例

### 3. 知乎 — 权威背书

| 环节 | 操作 |
|------|------|
| **定位** | 地缘政治 + 量化投资交叉领域KOL |
| **回答策略** | 搜索"油价""黄金""中东""美联储"相关问题，用报告数据回答 |
| **专栏文章** | 完整中文版报告（学术风格，加引用和数据来源） |
| **引流方式** | 个人简介 + 文章底部："更多量化模型和六大师推演，见公众号" |

### 4. 知识星球 — 付费变现（替代Substack）

| 环节 | 操作 |
|------|------|
| **定价** | ¥299/年（早期）→ ¥499/年（稳定后） |
| **内容** | 每周量化报告 + 决策树更新 + 六大师周度投票 + 问答 |
| **权益** | 完整版报告 + 监控指标推送 + 每月一次直播解读 |
| **冷启动** | 前50名 ¥99/年，用公众号/雪球文章导流 |
| **续费** | 目标续费率 60%+ |

### 5. 小报童 — 轻量付费（替代Substack邮件）

| 对比知识星球 | 更适合"独立分析师"人设 |
|-------------|----------------------|
| **定价** | ¥99/年 |
| **内容** | 每周一篇付费文章（精简版报告） |
| **优势** | 微信内直接阅读，无需跳转App |
| **与知识星球关系** | 小报童=标准版，知识星球=进阶版+社群 |

```
低价层（筛选付费意愿）

├── 小报童: ¥99/年，每周1篇深度

高价层（高端变现）

```
