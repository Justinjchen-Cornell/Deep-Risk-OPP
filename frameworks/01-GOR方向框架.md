# 🧭 GOR 方向框架

> **一句话**：用金油比一个指标，决定你今天该配什么方向。
> **什么时候打开**：每天早上看到决策卡时、做任何投资决策前。

## ⚡ 30秒速查

```
GOR ≥ 45 → 🔴 原油极端低估 → 先跑「机制筛选器」(v2.2) 再动油气腿：
   🟢绿 = 恐慌✓ 且 ≥2/3 → 油气腿按表(25%)，三三四分仓、首笔≤30%
   🟡黄 = 观察区        → 油气腿上限减半(12%)
   🔴红 = 体制重定价候选 → 油气腿=0，勿以「回归逻辑」新建仓
GOR 30-45 → 🟡 修复周期 → 50%仓位 → 油气(20%)+黄金(15%)+A股(15%)
GOR 20-30 → 🟢 估值均衡 → 30%仓位 → 黄金(15%)+A股(20%)
GOR < 20 → 🟢 原油泡沫 → 10%仓位 → 黄金(7%)+现金(90%)
```

## 🧭 v2.2 机制筛选器（2026-09 新增）

> 来源：「定量建模训练场」延伸研究 #01（比值极端后回归：55 事件 / 半程 64.7% / 1/3 失败）与 #02（机制论证）。
> 一句话结论：**GOR≥45 是「极端报警器」，不是「概率规律」——恐惧才是分水岭。**

**三个屏幕**（免密钥数据、事前可算；实现 `data_pipeline/screener.py`）：

| 屏幕 | 问题 | 判据 |
|---|---|---|
| ① 拆腿 | GOR 走高是「油跌」还是「金涨」驱动？ | 12 个月金/油贡献对比；金腿 → 退出油回归逻辑 |
| ② 恐慌签名（**必要条件**） | 市场在恐慌吗？ | VIX ≥ 其滚动 10 年 P80（恐慌组回归率 82.6% vs 平静组 47.8%） |
| ③ 油迫近 | 油到「被错杀」的位置了吗？ | WTI ≤ 其滚动 10 年 P25（供给压力粗代理） |

**裁决与动作**（v1.1：恐慌签名是一票必要条件）：

| 裁决 | 条件 | 油气腿上限 | 历史预期 |
|---|---|---|---|
| 🟢 绿 | 恐慌✓ 且 ≥2/3 | 100%（25%），三三四分仓、首笔≤30% | ≈83% 半程回归 |
| 🟡 黄 | 其余中间态 | 50%（≈12%） | 观察，等信号 |
| 🔴 红 | 无恐慌 且 ≤1/3 | 0 | 体制重定价候选，勿用回归逻辑 |

**配套机制**：
- **前向注册卡**：`scripts/make_card.py` → `注册卡/`，**填完 commit 即冻结**，到期（6/12 个月）只读对账；
- **尝试台账 / 先写规则再看数据**：见延伸研究 #03（`studies/03-事前注册/`）；
- 上限系数可调：`config.SCREENER_OIL_CAP`（绿 1.0 / 黄 0.5 / 红 0.0）。
- 范围说明：v2.2 只对 ≥45 极端区设油气腿上限（研究样本范围）；30–45 修复周期区暂不设限。

## 📐 计算公式

```
GOR(布伦特) = 黄金(美元/盎司) ÷ 布伦特原油(美元/桶)
GOR(WTI)   = 黄金(美元/盎司) ÷ WTI原油(美元/桶)

目标区间: 20-30 (历史均衡)
当前状态: ~39–41 (2026.09) → 修复周期；机制筛选器当前：红（无恐慌）
```

## 🎚️ 风险修正器（仅调仓位，不改方向）

| 条件 | 修正 | 逻辑 |
|------|:---:|------|
| DXY > 99 | -10% | 强美元压制黄金+大宗+新兴市场。DXY受[[04-Token美元进度|Token美元换锚]]进度影响 |
| DXY < 98 | +10% | 弱美元利好全球风险资产 |
| 10Y > 4.3% | -10% | 高利率增加持有成本 |
| 10Y < 4.2% | +10% | 低利率环境利好配置 |
| PBoC 连续2月购金≥2吨 | 黄金仓位锁死 | 央行买盘是底 |
| WTI < 60日均线×0.85 (且为需求冲击) | 油气强制降至5% | 动态硬止损(v2.1)：区分供给冲击vs需求冲击 |

**最终仓位 = 基础仓位 ± DXY修正 ± 10Y修正**（范围: 5%~80%）

## 🔴 硬规则（不可违反）

1. **WTI 动态硬止损 (v2.1)** — 替代了旧版静态 $75 规则：
   - **触发条件：** WTI < 60日均线 × 0.85 **且** 下跌为需求冲击驱动（GOR未显著上升 + VIX>20确认）
   - **供给冲击覆盖：** 若GOR在5日内上升>5%且VIX<20 → 判定为供给冲击 → 硬止损被覆盖，油气仓位保持框架水平
   - **绝对底部：** WTI < $60 → 无论冲击类型，硬止损无条件触发
   - 触发后油气仓位强制 ≤ 5%
   - *设计理由：2026年6月伊朗和平协议后WTI跌破$75，但属供给冲击而非需求冲击，旧版静态规则过于保守（少赚~2-3%组合收益）。v2.1通过GOR方向+VIX辅助判定冲击类型，区分散户恐慌和结构性需求崩塌。*
2. **不加杠杆** — 终身铁律
3. **不做空** — GOR框架不适用做空逻辑
4. **不单一品种满仓** — 单资产上限25%
5. **现金≥40%** — [[06-风控日历|SpaceX IPO窗口期]]规则（2026.06起）
6. **分批建仓** — 至少3批，不一次打满
7. **黄金底仓≥15%** — PBoC购金期间锁死
8. **每月复盘** — 对照[[07-决策审计框架#GOR方向判定审计|决策审计]]核查GOR方向准确性
9. **机制筛选器 (v2.2)** — GOR≥45 时，油气腿先过筛选器；红区不得以「回归逻辑」新建油气仓（v2.1 硬止损不受影响）

## 📊 历史参考

| 时期 | GOR峰值 | 持续时间 | 回归方式 |
|------|:---:|:---:|------|
| 2020.04 | 60+ | 12个月 | 原油反弹+黄金横盘 |
| 2016.01 | 40+ | 18个月 | 原油慢涨 |
| 2008.12 | 30+ | 24个月 | 危机后原油复苏 |
| 1998.12 | 28+ | 36个月 | 亚洲金融危机后 |

**规律**：GOR从极端位置回归的**方向确定**（原油涨或黄金跌或两者同时），**时间不确定**（12-36个月）。
